1. The four limitation classes (the tags used everywhere)

TagClassMeansEffect on the verdict
SSemantics The engine's execution model cannot express the rule (Principle 1: CPU runs sequential and parallel; the GPU runs only parallel). Blocker — ✗
RReproducibility Runs correctly, but not bit-reproducibly (Principle 2: CPU is exact, GPU is statistical). Note — still ✓
FFast path Runs identically either way; only ms/generation differ (Principle 3). Note — never an error
CCapacity A resource bound with a number, not a concept. Blocker with the number stated
