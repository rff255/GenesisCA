1 · The force law (per neighbour pair, from their WGSL)

minR, maxR, rule are all PER-PAIR — three K×K lookup tables keyed species × species (asymmetric). Below minR the force is always repulsive; between minR and maxR it is a tent peaking at the midpoint with height rule ∈ [−1,1].
Graph skeleton (Behaviour Step)
Friction runs in-graph (f is a bounded model attribute → a live simulator slider); the engine integrates with momentum = 1.0. Spawn = Agent Init → Loop(Count ← model attr N) → Create Agent(rand·W, rand·H) → Set species(rand 0..K−1) → Add To World.
