5 · Degenerate cases (all no-crash)

  • No compatible output — the node is spliced on the INPUT side only; the original edge is still removed (as requested). Nothing dangles.
  • Composite (vector / color) links — the composite rules live in portsCompatible, so only composite-capable nodes are offered and only a matching composite output auto-wires.
  • Source is a reroute — getOriginPortInfo already resolves a reroute's relayed category + dataType.
  • Consumer is a macro instance port — no static port def exists, so the consumer origin falls back to the handle's category with dataType: any (the editor's permissive default).
  • Edge deleted while the menu is open — the commit is a no-op that just closes the menu; no snapshot is pushed.
