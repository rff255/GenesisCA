2 · The policy — what Auto picks under each contract

ContractLayerAuto picksWhy
Exact CA grid WebGPU if every grid gate passes, else WASM The GPU grid seeds a per-cell PCG and setRngSeed re-derives those streams — a fixed seed does reproduce a run on this device.
Agents WASM if its gate passes, else JS The GPU agent engine seeds its per-agent PCG once at runtime creation; setRngSeed never reaches it.
Statistical CA grid WebGPU if every grid gate passes, else WASM Unchanged — the grid policy is contract-independent.
Agents WebGPU → WASM → JS The library policy: fastest engine the gates accept.

The asymmetry is the point — and it is measured, not assumed. A 5-run Overseer sweep on the WebGPU grid reproduced (460.8 ± 15.707, identical across presses), while the documented library exceptions that force CPU for sweep reproducibility (Cubic GRA, Graph Metrics) are agent-target exceptions.

4 · Overseer Experiments — the methodology line

One line under Run / Abort, derived from the contract + the resolved engines. It answers the only question that matters before you read a number off a sweep: is a single run a result?

Statistical contract — runs are draws from one distribution. Use repeats + aggregates (Collect Sample → Series Stat: mean / std / ci95); a single run is not a result.

Overseer Experiments

A third form covers Exact with a GPU layer: “…pins a run on this device. The GPU is f32, so these numbers are engine- and device-specific: don't compare them against a CPU run.” A live contract violation replaces the line with its amber text.

Coherence holds structurally. Every shipped file carries an explicit engine on both layers (C4's migration never produces 'auto'), so the resolution takes the explicit branch — which the contract does not touch. The gate asserts this model by model, both layers.

6 · What this phase does NOT touch

No compiler, worker or engine file is opened for writing — the contract is a resolution + display property. check-compile-identity must report all 29 models byte-identical. The engine's own safety nets, the worker demotions, and every explicit engine choice behave exactly as before.
