PR1 — M0a: Dimension radio + Topology checkboxes NEW

Two new clusters in the modeler Properties tab. The Dimension radio joins the Structure section (with a Grid Depth field that appears only in 3D); the Topology checkboxes join the Execution section above Variegated Cells. Bond-Graph Agents is rendered but hard-disabled this milestone. No behaviour change for existing models — every legacy file migrates to 2D grid.

Schema + migration

ModelProperties.dimension?: '2d'|'3d' (absent → '2d'), ModelProperties.gridDepth?: number (absent → 1, so W*H*1 === W*H byte-identical), CAModel.topologyMode?: { gridCells, agents } (absent → {gridCells:true, agents:false}). The LOAD_MODEL reducer seeds all three; the UPDATE_TOPOLOGY_MODE reducer rejects an all-false selection (≥1 invariant). Distinct from the legacy ModelProperties.topology:'2d-grid' string enum, which is untouched.
