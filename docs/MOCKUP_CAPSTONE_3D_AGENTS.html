② 3D tension-axis division — the genuinely-new math (engine, PR2)

2×2 → 3×3 symmetric eigensolve

A bonded cluster divides along its mechanical axis — the principal eigenvector of the bond-tension tensor M = Σ wₖ·(r̂ₖ⊗r̂ₖ). In 3D, M is 3×3 symmetric; the principal eigenvector comes from a closed-form Cardano/Smith trigonometric solve (branchless, O(1), no Jacobi sweeps).

  • Parallel branch, not a reducing solver: D===1 → the existing 2×2 solver (byte-identical 2D); 3D is a separate path.
  • The #1 NaN source: the acos(r) argument MUST be clamped to [-1,1] — a symmetric tissue division NaNs the daughter without it. minorEig3x3 shares the same clamp.
  • Proof: match an independent eigh reference on random symmetric tensors (PR2 DoD #5) — the only real correctness gate.
