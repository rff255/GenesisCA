Right-drag to pan while a wire is held

Connect two nodes that are far apart without letting go of the wire. Editor layer only; the compilers are untouched.

1 · The gesture, step by step

1
LMB-press an output port — the wire follows the cursor (unchanged).
2
Wheel — zoom out to see where you are going (unchanged; already worked).
3
RMB-press and drag — the canvas pans by the pointer delta. The wire keeps following the cursor. new
4
RMB-release — nothing happens: no context menu, the wire is still held. new
5
LMB-release on the consumer port — the connection is made (unchanged). On empty canvas instead → the connection-drop menu (Reroute / add-and-connect), unchanged.

3 · Why React Flow could not do it, and where the fix sits

Mouse events, not pointer events: a second button pressed while the first is held fires no pointerdown / pointerup (only a pointermove whose button names it), while the compatibility mousedown / mouseup fire per button — which is also what XYHandle listens to.
