The palette notice is the missing half of the gate: the app already hides nodes a setup rules out; now it says so, counts them, and links to the tab that turns them on (→ Agents when the hidden nodes are capability-gated).

The selected indicator's editor still opens in the second panel — the master-detail machinery moves with the list.

4. What stays exactly the same

  • Every control dispatches the SAME reducer action with the SAME payload — this is a presentation refactor; no model field is added or renamed, no compiler / worker / engine file is touched.
  • The disabled-in-place rules (async under WebGPU, the last remaining layer, Seed count under Seed pattern = None, Variegated in 3D) and the hidden-when-impossible rules (Georeference behind GIS, Agents tab behind the Agents layer, Reset-restores-board behind an embedded board) are preserved.
  • Collapsed sections persist per id in localStorage as before (new ids — the old set is simply dropped).
