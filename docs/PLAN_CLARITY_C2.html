C2 — the Generation Pipeline panel

A read-only, ordered list of what happens each generation for THIS model — with owner attribution (your graph vs the engine), a tempo tag per phase, the resolved numbers each phase reads, and inactive phases named with the capability that turns them on. Every activity bit is computed by the same resolver the engine consults, so the panel cannot drift from what actually runs.
