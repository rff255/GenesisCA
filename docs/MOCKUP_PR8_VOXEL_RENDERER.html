A 3D model swaps the 2D canvas for a sibling WebGL2 canvas. Instanced unit cubes (one per alive, alpha>0 cell — the full volume is NEVER instanced), an orbit camera, and a clip/slice plane as the PRIMARY see-inside (fragment discard, not depth-sort). Colour-id picking feeds the same paint/inspect protocol.

Architecture

src/simulator/render/gl3d.ts — Gl3DRenderer: a 36-vertex unit cube + per-instance [cellIndex, r, g, b, a] (the vertex shader decodes x/y/z from the flat index via uW/uWH). uploadColors compacts only alpha>0 cells. Orbit camera (yaw/pitch/dist/pan). Clip plane = fragment discard past a bounded axis cut. Opt-in per-cell alpha = GL blend + back-to-front instance sort. Colour-id pick = a second FBO pass encoding idx as RGB, nearest cube wins via depth, readPixels at the cursor (Y-flipped).

SimulatorView seam: a sibling <canvas ref=glCanvasRef> (2D canvas hidden when 3D). draw() (useCallback([]), ~20 call sites) branches on is3dRef and reads camera/clip/alpha/depth via refs. Pointer effect: LMB-drag orbit, wheel zoom, MMB/Shift pan; no-drag LMB = paint the picked voxel (radius-1), Shift+click = inspect. Screenshot + recording read the GL display buffer (display resolution). WebGPU is forced off in 3D (the GL renderer needs the CPU colors buffer that WebGPU direct-render skips). DEV hooks: window.__sim3dCamera / __sim3dClip / __sim3dPick / __sim3dRenderer / __sim3dRedraw.
