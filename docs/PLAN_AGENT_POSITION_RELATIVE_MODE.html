Get Agent Position — Absolute / Relative mode

One node, a mode toggle. Absolute = raw position by handle (today). Relative = torus-shortest displacement from a reference agent (defaults to self), reusing the engine's wrap. Lockstepped across JS / WASM / WebGPU, 2D + 3D. Existing nodes compile byte-identically.

The node — before & after

Before today

// absolute — unchanged
_vN_x = _agentX[agentId];
_vN_y = _agentY[agentId];

After · Absolute + mode

// byte-identical to "before"
_vN_x = _agentX[agentId];
_vN_y = _agentY[agentId];

After · Relative new

// relative — torus folded
dx = _agentX[agentId] - _agentX[ref];
if (_fieldBoundaryTorus) /*fold*/;
_vN_x = dx; // ref = idx (self) by default

value port (unchanged) new Reference input (relative only)

Why "Relative" reuses the engine wrap (not raw subtraction)

On a torus, two agents either side of a seam are close, but target − self points the long way around. Relative mode folds each axis to the shortest path — exactly what getAgentOffset already does — so cohesion/steering vectors stay correct across the boundary.

No ABI change. Relative mode reads the world bounds (_fieldW / _fieldH / _fieldD / _fieldBoundaryTorus) that already ride the agent-loop signature for getAgentOffset — so JS↔WASM stay bit-exact (f64) and WebGPU matches statistically (f32). The relative emitters are clones of each target's existing compileAgentOffset, minus the Distance output, with ref in place of the hardcoded idx.
getAgentOffset is kept. It still ships the Distance output and is the ergonomic self→target shape used across the docs/examples. Relative getAgentPosition generalizes it (arbitrary reference); the two coexist with no redundancy hazard (distinct node types → distinct CSE keys).

Verification

  • Byte-identity (absolute): compileAll before/after on an existing absolute node — JS string, WASM bytes, WGSL all identical. Re-run Boids polarization + the JS↔WASM parity samples.
  • Correctness (relative): relative (ref unwired) == getAgentOffset (dX, dY[, dZ]) for the same target, including a torus-seam case; wired ref == target.pos − ref.pos folded.
  • Cross-target: JS↔WASM bit-parity (f64, exact); WebGPU run (f32, within the existing agent tolerance).
