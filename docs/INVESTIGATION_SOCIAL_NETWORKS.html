TL;DR The simulation tier is already there. The file seam is not.

GenesisCA is already a graph-rewriting engine: agents are nodes, bonds are edges, bond attributes are edge attributes, and Rewire Bond is an atomic primitive most SNA toolkits do not have. Four things are missing, and only one of them is hard.

gap  Nothing can create a bond from data

Verified: a grep for bond across every importer and import dialog returns zero matches. pasteAgents has no bond field; formBondBatch was removed and exists nowhere in src/. The only bond-creating messages are the single-pair formBond / breakBond the Glue / Cut brush sends.

gap  No generators

ER / WS / BA / SBM are all expressible as rule graphs — but hit an O(N²) enumeration, a per-generation request-queue depth of 8, and the rule that bond verbs are invalid in the Agent Init Event. Belongs in the importer, not the rule graph.

gap  No centralities, no communities

Six graph indicators ship (N, E, mean/max degree, degree histogram, components). Everything an SNA user opens first — PageRank, betweenness, clustering, modularity — is absent.

hard  The maxBonds ceiling

The bond store is ELLPACK — maxAgents × maxBonds rectangular. Social graphs are scale-free. A 100k-node BA graph would need 3.19 GB of bond store for 300k edges. See §4.

The unusual strength, stated honestly. Coevolving state-and-topology models (adaptive voter, Holme–Newman rewire-on-disagreement, adaptive SIS) are awkward in NetworkX — you rebuild the graph every step — and awkward in NetLogo. GenesisCA has an atomic per-agent structural request queue with Form / Break / Rewire / Transfer / Form Between / Break Between, harness-checked invariants, and a force layout that keeps up at 10⁴ nodes. That combination is genuinely rare, and it is already shipped.

The attribute vocabulary that is effectively standard

Not a spec — a convention consistent enough that auto-mapping on these names will hit most real files.

Edge attributes

weight — the one universal edge attribute; NetworkX, igraph and Gephi all special-case it. Then type / kind / relation (multi-relational networks), sign (±1, balance theory), timestamp / start / end.

Node attributes

id, label, name; group / community / club / modularity_class; x, y, size, color; and the computed columns a tool writes back — degree, betweenness, pagerank, eigencentrality, clustering.

That last group is the practitioner's loop: simulate → compute metrics → write them onto the nodes → export → plot elsewhere. It is why the export side wants a node table with metric columns, not just an edge list.

Format sketches and keyword names were written from domain knowledge and then spot-checked online. Confirmed: NetworkX deprecated the link keyword in 3.4 and flipped the default serialization key "links" → "edges" in 3.6, so real files carry either — an importer must accept both keys. Still from memory: UCINET DL's keyword casing (harmless — UCINET is case-insensitive). Check the other specs before turning a sketch into a parser.

2 The mapping: file → agents + bonds

Every piece on the right already exists. The only thing that does not is the arrow in the middle.

The one non-obvious constraint. pasteAgents allocates slots with allocAgentSlot() in sequence and replies with nothing — so the file-id → slot-id map exists only inside the paste loop. The bond list therefore cannot be a second message keyed on file ids. Either agents and bonds travel together (recommended: an optional bonds member on pasteAgents, indexed positionally into agents), or the paste must start reporting its allocations. The first option is additive, and as a bonus it closes the documented "pasted agents arrive unbonded" gap for the clipboard too.

4 The maxBonds ceiling — the one hard constraint

The bond store is ELLPACK: maxAgents × maxBonds rectangular, ragged only in that bondCount[i] ≤ maxBonds. Social graphs are scale-free. Those two facts collide.

BA rows and the store arithmetic measured this session; the published datasets' N and E are confident, their max-degree column is from memory. The argument does not depend on the exact figures — only on max ≫ mean, which is definitional for scale-free graphs and is confirmed by the measured rows.

The honest scope statement. GenesisCA can hold graphs bounded by maxAgents × maxDegree, not by edge count. The classic SNA corpus (≤10³ nodes, max degree ≤10²) is comfortable; a mid-size collaboration network costs tens of MB; a hub-heavy ego network or a 10⁵-node scale-free graph is out of reach without a CSR bond store — which is its own milestone, and only worth it when someone actually needs it. Until then the importer must compute the max degree before it does anything and either raise maxBonds or refuse with the exact number. Silently truncating a hub is the one outcome that must never happen.

5 Directed edges — keep D2, use the attribute idiom

GRA decision D2: a bond is ONE object stored TWICE. Both slots hold the same values; invariant I2 (harness-checked) requires it. So an asymmetric bond attribute is not merely discouraged — it is unrepresentable without breaking a machine-checked contract.

Three encodings, increasing power, all I2-clean

NeedEncodingThe rule reads it ascost/slot
a simple arc (the 95 % case) ONE integer bond attribute source = the tail agent's id outgoing = (source == Get Self Handle) — one Compare4 B
reciprocal arcs preserved TWO bool attributes arcLoHi/arcHiLo, relative to min(a,b) (self < partner) ? arcLoHi : arcHiLo — Compare + Value Switch8 B
asymmetric weights (a trusts b 0.9, b trusts a 0.2) TWO float attributes wLoHi/wHiLo, same convention the same Value Switch16 B

The min/max convention rather than a packed bitmask is deliberate: the Math node has no bitwise operators, so a two-attribute form costs one Compare where a mask would cost modular arithmetic.

Why not break D2?

Asymmetry would thread a second parameter set through every bond mirror: the WASM and WebGPU emitters, moveBondSlot's compaction field list, serializeAgentStore, setBondFields, drainAgentBondRequests. And the physics reads restLength/stiffness from the local slot — an asymmetric spring is unphysical.

What the importer must do

Read edgedefault / *Edges vs *Arcs / "directed" / Type, then offer a Directedness control. Note that formBond refuses a duplicate pair, so a reciprocal arc pair is one bond — merge and report, or use the arc-pair encoding.

The hub effect is visible, and it is a design rule. At the same N and E, clustering costs 3× more on the scale-free graph than on the small-world one (23 vs 8.1 ms at 10k; 200 vs 60 ms at 100k) because the per-node inner loop is O(d²) and one hub dominates. Cost any new metric on a scale-free graph, never on a lattice or a ring.

tier 1 Per-generation indicators

density · largest-component fraction · isolated count · assortativity · max core number. All O(N+E), effectively free next to the shipped degree pass. Extend graphMetrics.ts — CPU-side by design, like the six that ship.

tier 2 Batch / frame tempo

mean local clustering + triangles · PageRank · eigenvector centrality. These want an explicit cadence, not the per-generation indicator path.

tier 3 On-demand actions only

closeness · betweenness · diameter · community detection. Nothing that takes 21 seconds may sit on the generation loop. The Overseer is the closest existing home — and where an "analysis action" lives is a genuine open design question.

per-agent Write an attribute, don't add a node

Colouring by PageRank is the canonical SNA picture. A per-agent metric node would need all three agent targets — and would not even work: PageRank, betweenness and community are global iterative quantities, not local computations. A worker-computed pass writing a designated agent attribute needs zero per-target emit and zero new nodes.

7 The recommendation

Ship N1 and N2. Defer the rest until a real model asks.

N1 — Network import (agents + bonds)  the whole unlock

One new pure module, one dialog, one additive worker field. Formats in priority order: edge list CSV/TSV (with an optional node table), node-link JSON, GraphML.

ALL-TARGET DELIVERY, by construction. An import is a worker mutation of the CPU store, so it is compile-target-agnostic — exactly like pasteAgents, paintManual and importGridValues. No compiler file is opened; check-compile-identity is unchanged by construction. The same argument the GIS importers shipped under. New graph indicators are CPU-side by design; the per-agent metric pass writes an ordinary agent attribute — so nothing in this plan needs a per-target emit.

N2 — Generators + the measurement tier

  • A Generate tab on the same dialog — ER, WS, BA, SBM, RGG. Seeded, deterministic, producing the identical {agents, bonds} payload. Beats a seedPattern sibling and sidesteps the O(N²) / queue-depth ceilings entirely.
  • Cheap graph indicators — density, largest-component fraction, isolated count, assortativity, max core number. All O(N+E).
  • A worker-computed per-agent metric pass writing a designated agent attribute on a cadence. Not a node.
  • Export — edge list CSV + node table CSV with the computed metrics as columns (§1's practitioner loop). node-link JSON next.
