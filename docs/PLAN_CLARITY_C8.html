C8 — Presentational geometry: the taint check + the pipeline label

Proposal item P9, detection only. Nothing in the engine changes; the phase makes one property visible: does the layout physics decide anything, or only where things sit?

1. The framing — a GRANT of freedoms, not a gate

When the check passes

Layout is presentation — No rule in this model reads geometry into a decision, so the layout physics only decide where things sit — never what the simulation computes.

Green, informative. The force block collapses into one honest sentence.

When it does not

Layout is part of your rule — This model reads geometry into its rule, so the layout physics are part of what the simulation computes — not just how it looks. e.g. Get Nearby Agents · agents → For Each In Array → Form Bond · targetAgent

Not a warning. Reading a position is a promotion: the model is fully supported and stays in today's exact, seeded, lockstep regime. Grey, with the witness that made it so.

3. The criterion is DATAFLOW TAINT, not "no position-reading node"

Get Self Position→ Expression→ Create Agent · x⇒ PRESENTATIONAL

The Cubic-GRA-midpoint rule: geometry into a position write is a closed loop. The emergent topology is identical under any layout — only where things sit differs.

Get Nearby Agents→ For Each In Array→ Form Bond · targetAgent⇒ geometry → topology
Neighbour Density→ Compare⇒ decides whether to run ⇒ Divide Agent⇒ a geometric DECISION

A branch condition taints even when the value written is a constant. Local variables are conduits, not sinks — taint flows through them (which is exactly what keeps Boids clean).

4. What taints with no wire to follow

Auto-bond

The engine forms and breaks bonds by distance, so the topology the rule reads was built from where agents sit. Life on Bonds has a perfectly clean rule graph and is tainted by this alone.

Divide Agent · tension partition

The mother's bonds are split by the tension axis — geometry decides which bonds each daughter keeps. The alternate partition is slot-based and does not taint.

Field deposits

Secrete To Field / Affect Cells Under land on the cells under the agent, so WHERE it is decides which cells change — tainting even with a constant value.
