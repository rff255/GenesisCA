# Plan — Models Library browse tools + 3D lighting + 3D cell gaps

Illustrated mockup: [PLAN_LIBRARY_3D_VIEW_UX.html](PLAN_LIBRARY_3D_VIEW_UX.html)

Three independent UX features, batched (branch `sim_agent_fixes`). All are pure
UI / render-layer — **zero compiler, worker, or schema impact** (no `.gcaproj`
change; the library index gains additive fields regenerated by the Vite plugin).

---

## 1. Models Library — filter / sort / group + uniform cards + hover-scroll description

### Index metadata (vite.config.ts `modelsLibraryPlugin`)
Additive fields per entry (index.json is regenerated on every dev start / build):
- `modified` — the `.gcaproj` file's mtime (epoch ms) → powers date sorting + a
  small date stamp on the card.
- `dimension` — `'3d'` when `properties.dimension === '3d' && gridDepth > 1`,
  else `'2d'` → powers the 2D/3D filter and a card badge.
- `gridSize` becomes `W×H×D` for 3D models (was always `W×H`).

### Toolbar (ModelsLibrary.tsx, above the grid)
- **Search** — case-insensitive substring over name + description + authors + tags.
- **Category select** — one `<select>` of all tags (case-insensitive canonical,
  with counts, sorted by frequency); clicking a tag chip on a card also sets it.
- **2D / 3D segmented filter** — All · 2D · 3D.
- **CA Grid / Agents topology filters** *(feedback round)* — independent
  TOGGLES, not a radio (a model can run both layers at once): each toggle
  requires its layer; both on = models coupling a grid with agents. Fed by
  plugin-emitted `hasGrid`/`hasAgents` (from `topologyMode`; absent → grid
  on / agents off).
- **Sort select** — Name A→Z (default, the historical order) · Name Z→A ·
  Newest · Oldest · Largest grid.
- **Group by category** checkbox — sections keyed by each model's FIRST tag
  (untagged → "Other"); groups sorted by size.
- A muted "N of M models" count + all prefs persisted in
  `localStorage['genesisca_library_prefs']`.

### Uniform cards
- Cards get a **fixed height** (flex column): name (1-line ellipsis), authors
  (1-line each), description (flex-1, clipped), meta row pinned to the bottom
  (tags nowrap-clipped, grid size + date right-aligned).
- *(Feedback round)* height 172 → **224 px** (+30%), grid min column 280 →
  **308 px** (+10%), internal padding/margins cut roughly in half, and the
  title recoloured to the **accent** so it stands out.

### Hover-scroll description
- When the clipped description OVERFLOWS and the pointer rests on the card for
  ~0.8 s, the text auto-scrolls slowly to the end, holds, scrolls back, and
  loops while hovered (rAF, direct style writes — no React re-render). Leaving
  the card resets it. Cards whose description fits do nothing.
- *(Feedback round)* The hover **preview popover is TWO same-size 320×240
  panes side by side** — [title + full description | thumbnail] — centered
  horizontally on the card and placed just ABOVE it (flips below at the
  viewport top). The description pane follows the SAME auto-scroll rule when
  too long for the pane (shared `useAutoScrollOverflow` hook). No thumbnail →
  the description pane alone; neither thumbnail nor description → no popover.

## 2. 3D View — lighting controls

Current state: the voxel + agent-sphere shaders hardcode one world-space light
(`L = normalize(0.4, 0.8, 0.6)`, `lum = 0.45 + 0.55·max(0, n·L)`).

### Renderer (gl3d.ts)
- `Light3D { mode: 'camera'|'world'; bx, by; wx, wy, wz; ambient; diffuse; specular }`
  + `setLight()`. Per-frame world light dir:
  - **camera** mode — `right·bx + up·by + towardViewer·bz` (bz = √(1−bx²−by²)):
    the light is anchored to the VIEW, so orbiting keeps the shading constant
    (matcap/headlight-style).
  - **world** mode — the stored `(wx,wy,wz)` unit vector: the light is fixed in
    the SCENE, so orbiting changes the shading naturally (sun-style).
- Voxel FS + sphere FS gain uniforms `uLightDir / uAmbient / uDiffuse /
  uSpecular / uViewDir`; shade = `ambient + diffuse·max(0,n·L)` + a white
  Blinn-Phong term `specular·max(0,n·H)³²`.
- **Defaults reproduce the current look exactly** (world mode, the same vector,
  ambient .45 / diffuse .55 / specular 0).

### UI (3D View panel, SimulatorView)
- A **Lighting** block: a draggable **light ball** (SVG shaded sphere — drag the
  highlight dot to aim the light, the standard "sun position" widget) + three
  compact sliders (Ambient, Light = diffuse, Shine = specular) + a
  **View / World** mode pair + Reset.
- Dragging in world mode converts the ball position through the CURRENT camera
  basis (`cameraBasis` exported from gl3d) — you always aim the light "as seen
  from here", then it stays put in the scene.
- Persisted in `genesisca_sim_settings.light3d`.

## 3. 3D View — cell-gaps toggle

- The voxel pass hardcodes `uCubeScale = 0.92`, leaving a gap between adjacent
  cells (reads as a lattice). New **"Cell gaps"** checkbox (3D View panel,
  default ON = the historical look).
- OFF → scale **1.001**: cubes touch with a hair of overlap, which is
  deliberately NOT 1.0 — exactly-coplanar shared faces of neighbouring cubes
  z-fight along seam edges; the 0.001 overlap keeps every interior face
  strictly behind a neighbour's outer face, so the surface renders as one
  solid, gapless volume.
- Applies to the pick pass too (same uniform via `setCommonUniforms`), so
  clicking "between" cells still hits with gaps off.
- Persisted in `genesisca_sim_settings.cellGaps3d`.
