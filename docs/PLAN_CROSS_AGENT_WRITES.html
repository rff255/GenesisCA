Cross-Agent Write Semantics

Design plan · 2026-07-14 · companion to PLAN_CROSS_AGENT_WRITES.md

The one idea: OVERWRITE writes race across agents; ACCUMULATE writes don't. So the two capabilities get opposite rules — gate cross-agent overwrites (attribute/position/radius) to async only, but freely allow a new commutative Apply Force To Agent in both modes.

0 · What "Apply Force" actually does (myth-buster)

It is not "set the force". It is an accumulate onto a buffer that is zeroed every step — so one call looks like a set, N calls sum, and the engine adds its own physics on top.

Your gravity model — accumulate in a local variable, then one Apply Force — is equivalent to N Apply Force calls. Both sum.

1 · Overwrite vs accumulate — why the rules differ

2 · Part A — gate cross-agent overwrites (async-only)

Mirror the CA grid's Fundamental #4: in sync mode a unit writes only itself; neighbour-writes are async-only.

SYNC MODE — now (silent footgun)
Set Agent Attribute
DO → NEXT
Agent ← Get Nearby Agents
Value = 1

Compiles & runs — but the write races the target's own update. Nondeterministic; UB on WebGPU.

SYNC MODE — proposed
Set Agent Attribute !
DO → NEXT
Agent ← Get Nearby Agents
Value = 1

Badge + compile error: "Writing another agent requires Async agent mode." Self-writes stay legal.

Exemption — spawning is not a race. Configuring a freshly-createAgent'd handle (the newborn isn't concurrently written) stays legal in any mode. The gate fires only when Agent traces to an existing agent (Get Nearby / For Each Bond / Pick Random / …), not a one-hop Create Agent handle.
Nodes affected: setAgentAttribute · setAgentsAttribute · setAgentPosition · setAgentRadius. setVelocity is self-only → untouched.

4 · Sequencing & open decisions

Order: A1→A2 first (small, self-contained safety fix), then B1 (JS/WASM) → B2 (WebGPU atomic) → B3 (docs). A and B ship independently.

Owner decisions (2026-07-14):
  • resolved WebGPU async agents — no. Fundamentally unsupported (like the CA grid), so cross-agent-overwrite models are JS/WASM-only by construction.
  • resolved Newborn exemption — one-hop Create Agent trace.
  • leaning B on WebGPU — atomic-CAS scatter (keeps the node general + all-target). Awaiting final confirm.
  • resolved setAgentSprite-by-id — not gated (cosmetic).
