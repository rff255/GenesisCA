Agents Phase 2 — illustrated plan

Three workstreams, accompanying docs/HANDOFF_AGENTS_PHASE2.md: ① torus-correct neighbour math, ② the agent-brush overhaul, ③ independent grid/agent compile targets. Mockups per the CLAUDE.md "illustrated plan for UI/behaviour changes" rule.

① Torus-correct neighbour math (behaviour change — PR1)

The engine wraps every relative vector; Get Nearby Agents returns the correct cross-seam list. But the boids graph reads raw positions (Get Agent Position) and subtracts them itself — so near a seam the vectors point the long way. Fix: a new Get Agent Offset primitive (torus-shortest displacement) the graph routes cohesion/separation through.

Keep Get Agent Position raw (it's an absolute position, for field seeding). The new node is JS-only until Phase F (PR6/PR7) — like every agent node today.
