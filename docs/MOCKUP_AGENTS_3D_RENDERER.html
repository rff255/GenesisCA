PR5 — 3D Agent Renderer

Instanced sphere impostors + bond lines + agent pick, built ON the gl3d.ts camera/clip/pick framework. 2D agent models keep the byte-identical Canvas2D drawAgentsOverlay — the single fork is is3dRef.current at draw().

Render order: overlays → brush plane → voxel cubes → agent bonds → agent spheres → hover/cursor → gizmo. Spheres write gl_FragDepth so they depth-interleave with voxel cubes; the amber ring (hover) draws with depth OFF.

Sphere impostor

  • 2 triangles / agent (TRIANGLE_STRIP, 4 verts), static quad VBO + per-instance [x,y,z,radius,r,g,b,a] (8 floats, stride 32, divisor 1).
  • SPHERE_VS expands the quad along uCamRight/uCamUp by radius; carries the Z-up world centre + radius to the FS.
  • SPHERE_FS discards outside the unit disc, derives the analytic normal (Lambert shade), writes gl_FragDepth from the re-projected surface point, applies the SAME clip test as the voxel FS.
  • B1-renderer: setCamera stashes this.camRight/camUp from cameraBasis(cam) every call.

Z-up remap (the invariant)

A sphere at continuous agent (ax,ay,az) → vec3(ax-uHalf.x, uHalf.y-ay, uHalf.z-az) — col→+X, row→-Y, layer→-Z — so a sphere at (c,r,l) sits inside the voxel cube at cell (layer=l, row=r, col=c). The bond endpoints, the rings, and the back-to-front sort all use the same remap.

Pick (instance index ≠ slot id)

SPHERE_PICK_VS/FS encodes gl_InstanceID+1 into the reused pick FBO (raycast disc + gl_FragDepth → nearest agent wins). pickAgent(px,py) returns the compacted instance index; SimulatorView's instanceToSlot(snap, inst) walks snap.alive ascending — the SAME direction uploadAgents compacts — to recover the engine slot. Throttled to on-change (an FBO round-trip is a GPU sync).

2D path stays byte-identical

For a 2D agent model is3dRef.current === false at draw(), so the Canvas2D drawAgentsOverlay runs and the GL renderer is never constructed — pixel-identical to baseline. PR5 touches no compiler, so the lattice byte-identity holds by construction.
