Agent brush — drop Bond, add Push / Pull

Simulator › Agent Brush · branch updates

1 · The mode row, before and after

Before

addremovemove editgluecut bond

bond dragged a disc and auto-glued every pair inside it that was already within formDistance × contact. Needed a bonded model, needed the agents to already touch, and Glue covers the deliberate case — almost no applications.

After

addremovemove editpushpull gluecut

push / pull work on every agent model (no bond store needed). Glue / Cut keep their existing “hidden when Bonds = Off” gating. Alt+wheel cycles the new order.

2 · The law — magnitude falls off with distance from the centre

// per live agent within `radius` of the brush centre, d = torus-shortest distance
const falloff = 1 - d / radius;                 // 1 at the centre → 0 at the rim
const step    = intensity * dt * falloff;      // world units THIS tick
push: x += step * outward;
pull: x -= Math.min(step, d) * outward;         // never overshoots the centre
// then wrap (torus) / clamp (bounded), writing BOTH x and xNext
Intensity is world units per second at the centre. The caller pre-multiplies by the frame dt (clamped to 100 ms) before posting — otherwise a 144 Hz display would push 2.4× faster than a 60 Hz one for the same setting.

Why no velocity kick. It would feel more like a force, but it accumulates: at momentum 0.9 a sustained hold converges to ~10× the per-frame step, and at momentum 1.0 (Particle Life) boundedness depends entirely on the model's own graph-side friction. A position displacement is well defined for every Motion mode (static / velocity / force), every momentum value and every compile target — the same contract Move already has.
