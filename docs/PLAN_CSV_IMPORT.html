CSV Import — two flavours, one dialog

Agents from rows · the CA grid from a table of values. Illustrated plan for docs/PLAN_CSV_IMPORT.md.

1 · The two shapes of a CSV

Flavour A — agents

A row is an agent; a column is a field.

Flavour B — the grid

The table is the board; one chosen cell attribute.

Convention (decided, shown in the dialog): a CSV line is a grid row (height); a CSV field is a grid column (width). A 12×9 file gives a 9-wide, 12-tall grid — what you see in a spreadsheet is what you see on the board.
