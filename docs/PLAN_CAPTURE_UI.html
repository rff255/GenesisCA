Capture becomes the bottom-most element of the right-edge stack: the stats column (generation, agents, fps, targets) sits directly above it. Output actions on the right, view actions on the left, time controls in the middle.

The stats overlay is anchored to the bottom today, so it must be lifted by the cluster's height — the robust form is one bottom-right flex column containing both, so the two can never overlap no matter how many stat lines a model produces (agent models add several).

Two rules that outlive this change

1. Never unmount an inapplicable control — disable it in place with a one-line reason, so overlay geometry is stable and the user learns why instead of watching a control disappear. 2. A binary choice is a two-state segment, not a dropdown — a full <select> for an either/or was the most wasteful control on the bar.
