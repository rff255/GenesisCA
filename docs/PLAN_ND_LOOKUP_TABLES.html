5 · One emit story, six surfaces

flat = Σₖ clamp((axisₖ | 0) − minₖ, 0, dimₖ−1) · strideₖ        // strides baked at compile (pre-resolve `_dims`/`_mins`)

JS          _tbl[flat] || 0
WASM        f64.load(slot.offset + flat·8)          (i32 clamp chain + multiply-add)
WebGPU      bitcast<f32>(varAux[u32(off + flat)])   (values are small ints — exact in f32)
agentWASM   guarded f64.load in agent memory        (extras carry dims; layout-lockstep via one resolveAxes)
agentWebGPU auxF32[base + flat]                      (+ fixes the pre-existing row/col-vs-labelA/labelB port bug)

Legacy 2-axis tables keep today's exact emit (raw row*colCount+col, no clamp) — byte-identity for every existing model is the proof standard. Only axes-mode gets the unified saturating clamp.

9 · Interaction sequence

  1. Author the table — add a Lookup Table model attribute, switch to Multi-axis, declare State(tag) × Faces(0..6) × Edges(0..12) × Corners(0..8); value type Tag.
  2. Roll a rule — Randomize: seed 🎲, density 0.20 → 2,457 entries filled in one click; the data is IN the model (save = reproducible).
  3. Wire the graph — the Table Lookup node now shows State/Faces/Edges/Corners inputs, labeled from the axis names; feed it the three neighborhood counts.
  4. Run — the structure accretes from the 5×5×5 seed; Stop Event pauses at the grid edge; orbit/clip the voxel view.
  5. Explore — re-roll seeds live in the simulator panel + Reset; or run the Overseer protocol to sweep 50 seeds unattended and keep the journal of interesting ones.
