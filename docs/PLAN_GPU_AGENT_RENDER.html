2 · The readback policy — how every feature keeps working

The one-shot rule lives in ONE place (the worker message dispatcher), so no feature can ever read stale state — it just pays ~2 ms when it syncs. Interaction therefore works exactly as today (SandboxScience-style GPU brushes are a possible later upgrade, not a prerequisite).

4 · Phases + B (the sim-side multiple)

A1 — direct render (the milestone)

Render pipeline + attachAgentCanvas (clone of the grid's proven two-phase seam) + camera messages + the readback policy + the UI-sync driver. Gates: 2D · agents-only · WebGPU target · resident-eligible · no sprites/metaballs. Zero compiler changes.

A2 — same renderer, snapshot-fed

Upload the f32 snapshot instead of reading resident buffers → JS/WASM targets and per-gen GPU models lose the ~10 ms Canvas2D draw too. Same shaders, same gates minus residency.

B — bin-sorted mirror

B1: the hash build's scatter also writes a bin-sorted field-major mirror + sortedId; the engine force pass iterates contiguous runs (no compiler change). B2: fuse forEachInArray(getNearbyAgents) to iterate bin runs against the mirror, materializing canonical ids only where the graph consumes identity. Identity stays canonical — we sort a read-mirror, never the agents (bonds/inspector/brushes keep stable slots).

Why it's general: any model that gathers neighbours (Boids, GoL-on-agents, future) reads coalesced instead of scattered — the 2–4× GPU memory-pattern gap measured against SandboxScience.

6 · First-principles guarantee

Every gate keys on general properties: topologyMode, resolved agent target, agentResidentEligible (itself built from behaviour-scoped usage flags), sprite/metaball presence, OffscreenCanvas support. The render reads only engine-owned SoA fields that exist for every agent model; colour is whatever the model's own graph computed. Nothing anywhere inspects what rule the graph encodes — Particle Life is just the model that happens to hit the fast path hardest today; Boids hits it identically, and a future gas/swarm/ecology model hits it the day it's authored.
