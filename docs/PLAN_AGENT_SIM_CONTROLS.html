⑨ Nearby-agent gathering — already efficient (verify + document)

Nearby-agent queries already use a uniform CSR spatial hash — O(N), 3D-aware (z-major bins, 3×3×3 stencil), reused scratch — in all four sites:

Query siteStructure
Get Nearby Agents (JS emit)spatial hash + all-pairs fallback
Get Nearby Agents (WASM emit)same hash, copied into agent memory

A uniform grid is the right structure for near-uniform agent density (an octree wins only for highly clustered/sparse data & has worse cache behaviour). No structural change — only fix the stale sim.worker.ts:863 comment that still claims "all-pairs O(N²)".
