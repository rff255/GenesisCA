2 · Behavior matrix — mode × scope

ModeSingleArea (footprint)
Add Place one agent at the cursor Scatter agents across the shape footprint (density-driven; today's seed, now shape-aware)
Remove Remove the one nearest agent Remove all agents whose cell ∈ footprint
Move Drag the one picked agent Rigid group drag — translate every agent in the footprint by the drag delta
Edit Click an agent → prefill panel → Apply to that agent Stamp the checked overwrites onto all agents under the footprint (live)
Glue / Cut / Bond Unchanged — inherently two-agent / area-scan; the Single/Area toggle is hidden for these.
Line + Move: a two-click line can't express a rigid drag, so with the Line shape, Move falls back to single-agent. Line + Add/Remove/Edit operate on the capsule region.

▸ Apply to agent

The same ManualBrushPanel rows the Add config uses — a Set checkbox + type-appropriate widget per property, unchecked rows dimmed & skipped. Geometry rows (Radius, Velocity, Position) are synthetic Attribute-shaped entries appended after the user's agent attributes.

  • Single: clicking an agent prefills every row from its live state (via getAgentState + a new decodeAttrValue), highlights it, and Apply writes the checked rows to that agent.
  • Area: click/drag the footprint stamps the checked rows onto every agent under it (live, no prefill).
  • Position defaults off — overwriting position in Area scope would stack agents; it's a Single-scope tool.

5 · Data flow & the one worker change

Only one worker-protocol change: extend the existing paintAgents handler with optional geom (radius → radius+targetRadius; velocity; position with the moveAgents x/xNext + torus discipline). Attributes still go through applyAgentSets. Works on JS / WASM / WebGPU-backed agents unchanged (baked-offset views — as moveAgents already proves) and runAgentColorPass runs after, so no per-target code.

6 · Fix carried in: Ctrl-drag resize

Today the Ctrl+LMB-drag resize is gated only on e.ctrlKey and reads/writes the CA-grid brush refs — so a Ctrl-drag while the brush targets agents silently resizes the hidden cell brush. The fix branches the onDown snapshot and onMove math on brushTarget==='agents' to read/write the agent shape state (identical per-shape math), in both the 2D and 3D handlers.

7 · 2D ↔ 3D parity

Every mode/shape/scope is wired in both pointer handlers. In 3D the footprint is projected onto the interaction plane via the existing mapStampToPlane (with volumetric ball/box Add via agentSeedPoints3d); single-pick goes through pickAgent3d → agentInstOrder → instanceToSlot (respecting the alpha-sort permutation); group-move drags on the plane; the cursor reuses gl3d's cell-highlight. Glue/Cut/Bond keep their current 3D behavior.
