Agent platform · retrospective & plan

AutomatosGT → GenesisCA

What a 2014 creature-sandbox teaches the 2026 agent platform — the genuine gaps, the idioms already in reach, what to adapt, what to leave behind, and where to take inspiration.

Old: AutomatosGT V1.71 · Python 2.7 + pygame New: GenesisCA agents · JS / WASM / WebGPU · 2D + 3D Method: source-level read + adversarially-verified feasibility pass
The one-paragraph verdict

GenesisCA's generalist, compiled agent platform already subsumes most of what AutomatosGT did — state machines, kinds, carrying, corpses, lifecycles are all expressible today as data-driven idioms. Two things are genuinely worth building: runtime spawning during behaviour (the one hard capability gap — eggs, projectiles, offspring) and a directional field-of-view node pair (a convenience & performance win — its capability is already emulatable). Everything else is documentation, sample models, and small UX polish. The collision model and the fixed update pipeline are better left behind — GenesisCA's are superior.

gap · build convenience · build as sugar today · document superior · leave

1What AutomatosGT is

A continuous, off-lattice creature sandbox: agents float on a torus world larger than the viewport, with a god-game camera (pan / zoom / minimap / follow). Each species is a Python class — bird, ant, spider, cockroach, bullet, soldier, ball — with its own sprites, named states, and a fixed Decide* pipeline. It is fully runnable today (portable Python 2.7 + bundled pygame 1.9.1).

ENGINE

Spatial-hash neighbour gathering (torus-tiled), directional FOV vision cone with a left/right split, body-radius collision + hard penetration correction, and a semantic type_ tag driving interactions.

CREATURES

Boids (Passaro), foraging+carrying ants (Sauva), an egg→adult→corpse life-cycle spider (Aranha), projectiles (Bullet), cross-species reproduction (Barata/Ovo), resources (Bola).

FEEL

A digital terrarium: place creatures by drag (heading+speed from the drag vector), pick a species by scroll, select & follow one, pause and poke, watch an ecology unfold.

Honest re-framing (from the adversarial pass). 4The genuine gaps — implementation designs

Both respect GenesisCA's non-negotiables: all three compile targets, 2D + 3D, JS↔WASM bit-parity, and the three mirrored agent-loop ABIs.

gap · build

4.1 · Runtime spawn — Spawn Agent node + Spawn Event root ★ flagship · effort M

Copy the proven Divide/Kill machinery. Structural mutations already stage per-agent request buffers during the parallel behaviour pass, then apply them in a sequential CPU structural phase. Spawn rides the same rails — all-target by construction.

Spawn Agent
Flow node: do→next, x/y/(z) · radius · vx/vy/(vz). No handle output. Config attrInit: defaults | inherit. Emits a plain staging write, byte-shape-identical to Divide.
Spawn Event
A 4th single-agent root (the analogue of Division Event). Runs once per newborn; outs spawnerId · myX/Y/Z · myRadius; its DO chain authors the child via universal Set Attribute / Set Velocity / Set Sprite.
Per target
JS: ordinary flow action. WASM: same i32.store8/f64.store Divide/Kill emitters. WebGPU: stage in AGENT_GPU_REQUEST_FIELDS, read back, commit CPU-side.
2D/3D
z/vz ride the trailing 3D block (like _divideAxisZ); hiddenPorts hides them in 2D → no-spawn 2D models byte-identical.
Critique fix folded in: the node carries an initial velocity (so bullets fly) — initAgentSlot doesn't set velocity, so the commit writes s.vx/vy/vz[newId] after it (mirroring the existing paintAgents.geom write). WebGPU request sentinels must be representable f32 — never a NaN (the divide-axis lesson). The three ABI mirror pairs + the new buildSpawnParams/Args are edited together; re-run the parity harness (0 mismatches).

convenience · build as sugar

4.2 · Directional FOV — Get Agents In View + Sense Hemifield effort M · no engine/ABI change

An angle filter injected into the existing gather. The heading (velocity) and torus-folded offset are already computed inside every nearby loop; the cone test is dot(heading, offset) ≥ cos(halfAngle). Zero new SoA fields, zero new ABI slots. With halfAngle = 180° it compiles to exactly the Get Nearby Agents bytes.

Get Agents In View
Array producer: OTHER agents within range AND the cone; optional AgentsLeft/AgentsRight split. Iterate with For Each — cone-scoped flocking/steering.
Sense Hemifield
Scalar reduction: L/R/Ahead counts + nearest dist/id, no id array, no scratch slot — enables lateralized taxis (Braitenberg vehicles) directly.
Heading source
Velocity by default; for still agents, reuse the existing spriteRotations facing field (already ABI-threaded — not a new SoA cost) or a wired input.
2D → 3D
2D cone in XY (L/R = 2D cross sign); 3D solid angle around the heading (L/R = triple product vs a stable up-reference).

5Already in reach — ship idioms, not nodes

The whole lifecycle vocabulary is expressible now. A built-in state/kind/FSM node would be a regression — it re-introduces the closed type the platform deliberately removed. Ship a small drag-droppable macro library (macros lower to primitives for free on all three targets) + docs + samples:

State Machine (N-state)

Switch-sugar: one branch per state + a Set Attribute(state) transition. Explicitly documented as sugar, not a built-in FSM.

Rigid Carry

Get Agent Offset → Set Agent Position (drag at a facing offset); the is_taken_ mutex is a bool claimed attribute set by id.

Lifespan Timer

Reads age; per-agent random lifespan via Get Random in the Init Event or under an age==0 first-step Switch (covers brush-seeded agents — the critique's fix).

Corpse → Decompose

Two-phase timer alive →(life)→ corpse →(rot)→ Kill, gating movement/forces on state=='alive'.

6What to leave behind

  • Hard penetration correction — GenesisCA's soft-sphere (CFL-clamped, non-penetrating) is strictly better. Keep it.
  • The fixed Decide* pipeline — data-flow graph order is more general (interleave a force with a vision query).
  • Class-per-species architecture — the opposite paradigm; the species ideas survive as sample models, not engine features.
  • A built-in species enum / runtime species picker — philosophically incompatible; the equivalent is a kind attribute + Switch, and named seed-config presets you scroll through.

7Simulator UX — small render-only wins

All TypeScript in the simulator; zero compiler/engine/parity work (the snapshot already ships vx/vy/vz; paintAgents already writes velocity; camera hooks exist).

Follow-agent camera — click to track; auto-clear on death Drag-to-set-velocity add-brush (heading+speed from the drag) Vision-cone debug overlay (companion to §4.2) Seed-config presets — the generalist "species picker"

9Broader inspirations

Vision completes the senses

GenesisCA has field gradients + omnidirectional proximity; a vision cone rounds out perception. The left/right hemifield is minimal-cognition (two numbers → emergent taxis) — expose it directly.

Emit-during-behaviour changes the dynamics

A fixed dividing population becomes open-ended birth/death — projectiles, spores, eggs, particles, predator-prey population curves. The qualitative expansion.

One canonical facing

Unify FOV heading, rigid-carry orientation and sprite rotation on the existing spriteRotations field — and consider a first-class "facing" so a still agent can look around.

The study loop & the terrarium

Select → follow → inspect is how you understand one agent in a swarm. Lean into the god-game framing; the sample gallery is the on-ramp.

10Recommended roadmap

A

Idioms & gallery effort S · no engine work

Macro library (State Machine / Rigid Carry / Lifespan / Corpse) + the six "today" sample models + a HelpView "agent patterns" section. Proves and documents the current platform, immediately.

B

Directional FOV + cone debug overlay effort M · no engine/ABI change

A contained clone of the gather on three targets. High legibility/perf payoff; upgrades Wolf & Deer and Braitenberg Moths.

C

Runtime spawn (Spawn Agent + Spawn Event, with velocity) effort M · the flagship

Follows the Divide/Kill request-buffer + structural-phase precedent; touches the three ABI mirrors (re-run the parity harness). Unlocks the whole reproduction/projectile class.

D

Simulator UX (follow-cam, drag-velocity, seed presets) effort S–M · render-only

Polish that makes the terrarium feel alive.

Deferred / nice-to-have: multi-spawn bursts (spawnCount); a first-class per-agent facing field; per-hemifield average offset/velocity outputs for true Braitenberg wiring; FOV in the division/init events.
