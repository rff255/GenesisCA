Actions on top, focused search, category-grouped list with an always-present highlight (first prefix match). Space → type → Enter drops the node where the cursor was.

Shared machinery. The pane menu reuses the connection-drop menu's renderQuickAddSearch helper (search input + ↑/↓-wrap + Enter/Esc + flat category-headered rows). The connection-drop branch adds a title and a wire origin (offering Reroute first + filtering to compatible ports); the pane branch passes no origin, so it lists every node available to the model and commits via addNodeAtPosition (no wiring). Placed singletons (Step, Init Event) are omitted.
