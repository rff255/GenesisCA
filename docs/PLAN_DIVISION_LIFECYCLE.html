1. Where a division actually happens

The Divide Agent node writes a request during the behaviour pass. The split runs at the end of the step, inside the structural phase — whose order is fixed and which shipped GRA models depend on.

2. Why Design A (staged daughter handles) is rejected

Daughter A is the mother's slot — reusing it is what keeps every neighbour's bondPartner entry valid. So a handle for daughter A can only be idx, and a write through it lands on a live, undivided agent that the rest of the step can still read. If the division is then rejected, there is nothing to roll back to.

Design A · the write that cannot be undoneviolates I5

4. Area vs volume

The split is rA = r·√f, rB = r·√(1−f) — in both dimensions (agentEngine.ts:2132-2133). That conserves r², so in 3D roughly a 29 % of the volume disappears at every symmetric division.

Today · conserve AREA (r²)default, unchanged
Opt-in · conserve VOLUME (r³)3D only
Divide Agent — proposed configD2
2D — the Conserve row is hidden, and the engine coerces a stale value to area.
3D — transported on the existing P5 partition table: no store lane, no ABI field, no emitter change on any target.
Byte identity, spelled out. dividePartitionKey gains a |area / |volume suffix. Every existing spec resolves to area, so the same suffix is appended to every key — the relative sort order is unchanged, so every 1-based _divideIdx is unchanged, so the emitted JS / WASM bytes / WGSL are unchanged. Inserting the field inside the key would silently renumber codes.

Two findings from grounding this document.
1 · latent footgun. Nothing stops a Form Bond being placed in a Division Event today; the emit references _bondFormReq, which the division signature does not carry, so the function throws at runtime, agentDivisionFn is nulled and every later division event is silently skipped. D4 makes it work; anything else must make it refuse.
2 · harness blind spot. check-compile-identity.mjs hashes agent.behaviourCode but not agent.divisionCode — the exact surface every Feature-1 phase touches. That is why D1 comes first.

6. Phases

D1
Close the byte-identity blind spot tiny
Add agent.divisionCode + the agent init code to check-compile-identity.mjs; re-capture the baseline. Every later phase’s “no shipped model changes” claim is unverifiable without it.
D2
Divide Agent conserve: area | volume (+ 3D myVolume) small
Spec + key suffix + resolver in dividePartition.ts; the two radius lines in divideAgent; one config row, hidden in 2D with the engine coercing. Zero ABI, zero layout, zero emitter change on any target. Gates: check-compile-identity (29 models unchanged), test-agent-abi, parity-agent-wasm (extended division-partition synthetic), Tier H, a real-worker 3D run.
D3
Division Event siblingId small
One output; one gated, trailing ABI scalar with a symmetric usesDivisionSibling flag so the DEV arity assert stays exact. Enables one event to configure both daughters. Gates: check-compile-identity (now covering the division code), test-agent-abi with and without the gate, audit-agent-layout.
D4
Division Event structural requests + the second drain medium — the headline
The queue block on the division ABI kind + a gated second drainAgentBondRequests; the bond verbs become legitimately valid in the division root. Gates: a new Tier Q in verify-graph-rewrite.mjs — a daughter bonds a third party in the same generation, I1–I4 after, an I5 capacity rejection, and a negative control proving the second drain does not re-apply a first-pass op — plus a real-worker run on all three agent targets.

Deferred, with reasons

  • Design B — per-daughter payload ports. Sound, but N attributes × 2 daughters × maxAgents lanes on three layouts, for a sub-need C1 already covers. Revisit on measured friction.
  • Design A — staged daughter handles. Rejected, not deferred: §2.
  • Agent Spawn Event. Deferred with a complete design (root, ports, ABI kind, the run-last ordering rule, and all eight call sites) in the impact map.
  • Redefining myArea in 3D. Shipped models read it on all three targets — document the πr² convention instead.
  • Splitting divideAgent’s -1/-2 overflow message. Real but unrelated; fold into whichever phase next touches the division loop.
